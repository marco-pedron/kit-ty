# kit+ty

**La cassa comune dei viaggi di gruppo, senza custode.** Ogni viaggiatore tiene i propri dollari digitali in un canale Lightning RGB verso l'operatore del viaggio; l'AI locale (QVAC) legge lo scontrino e divide la spesa; l'agente di ciascuno rimborsa chi ha pagato in pochi secondi, entro limiti fissati dall'utente.

Progetto per l'hackathon *Agentic Dollars on Bitcoin* (Torino, 17-18 ottobre 2026). Gira su Bitcoin **regtest**.
